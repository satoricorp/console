gx records which agent session produced each Git commit and uses that context
for AI code review and generated pull request summaries. You work in plain Git.

## Install

```bash
curl -fsSL https://download.gx.run/install.sh | sh
gx auth login
```

This installs bash/zsh completions and aliases, like `gxr`, for `gx review`.

## Basic Usage

You run exactly two gx commands: `gx init` once per repository to install the
Git hooks, and `gx review` whenever you want an AI review. Otherwise, use Git
as normal — the hooks record revisions, capture sessions, and publish on push
without any gx-specific commands.

```bash
cd your-repo
gx init                                # once per repo: installs the Git hooks
git add src/retry.js
git commit -m "add retry helper"       # hook records the revision
gx review                              # AI review before you push (optional)
git push                               # hook captures the session and publishes
gh pr create                           # gx Cloud adds the summary to the PR
```

Summaries require the [gx GitHub App](https://github.com/apps/satoricorp-gx)
on the account or org that owns the repo.

## Uninstall

```bash
rm -f ~/.local/bin/gx ~/.local/bin/gxr ~/.local/bin/gx-mcp
rm -f ~/.local/share/bash-completion/completions/gx ~/.zfunc/_gx
```

Installed Git hooks exit silently when the binary is absent, so plain Git keeps
working. Local data remains in `~/.gx`.
